# Raycast / uTools 能力差距矩阵

> 状态：Baseline / 执行矩阵
> 更新时间：2026-07-27
> 范围：CoreBox 常用能力、Tinycast / Wox / Vicinae / Sliprail / SuperCmd 等 launcher 动态、官方插件、SDK 文档、TuffEx 展示与 App Data / Everything 后续
> 非目标：复制竞品交互细节、一次性重做插件系统、绕过平台权限模型读取用户隐私数据

## 1. 基线来源

本矩阵只用于把 Tuff 当前能力和主流桌面效率工具的高频能力对齐，后续实现仍以 Tuff 的 local-first、typed SDK、权限诊断和可回滚原则为准。

- Raycast 官方 Windows 页面公开展示的核心能力包括 App Launcher、File Search、Clipboard History、Snippets、Quicklinks、Calculator、AI、Notes、Emoji & Symbols、Shortcuts、Window Management 和扩展生态。
- Raycast Store 公开导航把 Raycast AI、Raycast Notes、Raycast Focus、Clipboard History、Window Management、Snippets、File Search、Quicklinks、Calculator、Calendar、System、Emoji Picker 作为 Core Features，并展示 Chrome、VSCode、Google Translate、Notion、Slack、Linear 等高频扩展方向。
- Raycast Manual 的 Dynamic Placeholders 说明 Quicklinks、Snippets 与 AI Commands 可复用剪贴板、snippet、日期、时间、UUID、浏览器标签等动态占位符，Clipboard offset 依赖 Clipboard History。
- uTools 官网将“万能搜索框”“超级面板”和插件生态作为主入口，公开强调 Alt+Space 呼出搜索框、长按鼠标右键呼出超级面板、3000+ 插件应用、AI 制作插件应用与智能体。
- uTools 帮助中心列举的高频场景包括全局搜索、插件匹配、剪贴板/备忘快贴/本地文件匹配、快速翻译、随手计算、图片处理、聚合翻译、OCR、剪贴板、图片批量处理、JSON 编辑器、JavaScript 文档速查、启动软件、搜索系统设置和跨平台使用。

### 2.2 产品态势与 Tuff 机会

- **Tinycast 是感知级竞品，不是功能级竞品**：仓库创建于 2026-06-29，GitHub API 快照约 701 Stars；`v0.7.5` DMG 抓取时约 568 次下载。它只做应用启动、计算、剪贴板和快捷键，却把“3 MB、无账号、无遥测”表达得非常清楚。
- **Wox / Vicinae 是最直接的开源技术标杆**：Wox 已把 Go + Flutter、三平台、插件、AI / MCP 和云同步组合成稳定发布；Vicinae 以 C++ / Qt 编译型主壳承载 Raycast 扩展兼容，直接挑战“性能和生态不可兼得”的假设。
- **Sliprail 是最接近的产品定位竞品**：Windows / macOS / Web、Nora、文件与剪贴板、MCP 权限、截图理解和按扩展同步，与 Tuff 的 AI-native command center 叙事高度重合。
- **SuperCmd 的迁移漏斗值得优先学习**：完整复制 Raycast API 维护成本高，但导入 Quicklinks、Snippets、Script Commands、快捷键和扩展清单能显著降低切换成本。
- **不参加 Feature Count 军备竞赛**：Supermac 和 SuperCmd 已走宽功能路线；Tuff 更应优化“能力覆盖 × 命中率 ÷ 感知延迟与认知成本”。

Tuff 的竞争收敛方向：

1. **建立基础性能与包体预算**：记录 CoreBox 冷 / 热唤起、首条结果 p50 / p95、空闲 RAM / CPU、安装资产和解压后文件数；AI、插件 host 与重型 provider 不得进入无需它们的首屏 critical path。
2. **完成搜索质量闭环**：语义搜索现有延迟召回只能追加、不能重排已渲染项；应以精确、错拼、缩写、拼音、自然语言和混排基准验证最终排序，而不是只证明 embedding 管线存在。
3. **把跨平台变成验收矩阵**：Windows、macOS、Linux 的文件搜索、应用扫描、OCR、截图、更新和降级提示必须分别有 evidence；Linux 二等公民和 macOS updater / 架构遗留不能被“均有安装包”掩盖。
4. **做窄迁移器，不立刻重写兼容层**：优先导入 Quicklinks、Snippets、Script Commands、快捷键和扩展清单，保留 Tuff typed SDK 与 permission-gated runtime 边界。
5. **把受治理 AI 做成可见差异**：BYO / self-hosted provider、调用来源、数据去向、权限与敏感操作确认必须在产品面可见；基础 launcher 在未配置云 AI 时仍需完整可用。
6. **采用轻量默认态 + 按需增强态**：默认只支付应用、文件、计算、剪贴板和命令成本；插件、工作流、AI 与语义能力在实际调用时初始化，不分叉第二套 Lite 产品。

### 2.3 OpenCLI 调研边界

- 本机没有全局 `opencli`，本轮通过 `npx -y @jackwener/opencli` 调用。
- Hacker News 未检出有效 Tinycast 讨论，Reddit 返回空结果，Twitter / X 要求登录；`opencli doctor` 显示 daemon 正常，但 Chrome Browser Bridge 扩展未连接。
- 因此 OpenCLI 空结果**不能**推导为“没有社区讨论”。当前只把官方仓库、Release 资产、下载计数和产品文档作为可复核信号。

### 2.4 2026-10-11 Tinycast 复核

上文 2.1～2.3 保留 7 月快照，不代表当前能力。Tinycast 0.11.19 已覆盖 Raycast 扩展、窗口布局、笔记、AI／MCP 与本地听写；“只做四个基础功能”的竞争判断已不适用于当前版本。扩展 OAuth 支持近期有移除，不能把公开兼容声明理解成全量无损替代。

完整功能、近三个月重点、正负用户反馈及 Tuff 优化建议见 [Tinycast 竞品调研与 Tuff 优化方向](../../../engineering/reports/tinycast-competitive-analysis-2026-10-11.md)。该报告建议先稳住高频体验与资源成本，再推进窄迁移和按需增强；不修改本矩阵全局优先级或现有版本承诺。

## 5. 优先级收敛

### P0 - 最小补齐竞品常用体验

1. **Calculator 显式入口**：CoreBox `calc` / `calculator` / `calculate` / `计算` / `换算` 前缀已接入 PreviewProvider；后续只补 Store discoverability / 历史管理，不重复实现计算核心。
2. **Browser Data 后续**：Chromium bookmarks 首版已落地；下一步按 BR-020/030 做受限 History 只读副本、Safari 调研与显式 degraded reason。
3. **Everything 生产证据**：Windows 真机 evidence + 性能基线 + SDK/CLI 决策。
4. **App Launcher evidence**：macOS/Windows 扫描、启用/禁用、搜索/推荐过滤闭环截图或日志。

### P1 - 提升留存与生态

1. **Snippets placeholders**：date/time/uuid/clipboard 首批已落地；browser-tab、cursor 和 autopaste 后置。
2. **Emoji/Symbol picker**：`touch-emoji-symbols` 首版已落地，复制为主；recent usage、扩展数据集和 Store evidence 后置。
3. **Quicklinks 统一模型**：manual/pinned quicklinks 与 Browser Data 分源展示。
4. **Super Panel 式 Context Actions**：先基于 selected text / clipboard image，不做鼠标面板 UI 重写。
5. **SDK 文档任务流**：Localization SDK 已从运行时合同补到可搜索中英文文档；继续补“创建插件 -> 声明权限 -> 使用 SDK -> 发布 -> 共享内容包”的完整路径，并让其余 SDK card 都落到真实 route。
6. **TuffEx demo 场景化**：补 CoreBox item、Settings diagnostics、Store content、Plugin permission、Empty/Error/Loading 等真实产品组合 demo。

### P2/P3 - 审慎推进

- macOS Notes / Calendar / Reminders：必须先做权限、隐私和降级原因调研。
- Epic / Game Launcher：先澄清需求，再决定本地项目索引还是游戏库。
- Focus：保持长期债务，不进入 `2.4.11` 稳定化窗口。
