# Tuff v2.4.14 更新说明

## 摘要

- CoreBox 改善首次唤起输入、键盘导航和推荐，支持从目录直达常用操作，网址经内置 Browser 入口直开。
- 文件索引采用有界扫描、增量核对和主动让出 CPU，正文索引默认关闭。
- Home 新增文件夹项目与原生 CLI 会话续接，内嵌终端支持输入和窗口调整。
- 语音听写支持本机模型和云端渠道，保留录音草稿并可发送语音消息。
- 加固插件权限、隐私和登录会话；本地 MCP Host 作为默认关闭的 Beta 能力提供。
- 更新下载支持过期签名地址恢复，更新页保留本机安装历史和明确的失败状态。

## 新增内容

- 文件夹项目可在已有目录运行本地 AI CLI，跨面板关闭和应用重启续接供应商原生会话；内嵌终端使用原生 PTY。
- 安装本机语音模型后可选择端侧识别，云端听写与本机模型目录独立；模型安装和移除会自动更新可用路由。
- Home 保留听写录音草稿，支持回放、重新识别和发送语音消息；语音附件提供播放、暂停、进度定位、时长和波形。
- 内置 Browser 入口支持选择本机浏览器直开网址、配置搜索引擎和快捷入口；官方 JSON Formatter 支持格式化、压缩和校验。
- 主窗口新增命令面板，Home 输入工具条使用权限、模式和模型胶囊；技能库可直接读取已安装 Agent 的技能目录。
- 本地 MCP Host 可向兼容的外部 AI 客户端提供 Tuff 工具，仅监听本机回环，保留工具授权与用户确认边界。

## 变更内容

- 修复 CoreBox 首次唤起时输入框无法输入、窗口预加载路径错误和关闭动画时搜索内容空白的问题。
- 推荐结合真实使用历史、时间和前台应用，显示独立推荐原因；尚未形成习惯时不填充虚构常用项目。
- 键盘网格导航跟随实际列数，数字键可选择执行或定位；Esc 按层关闭浮层、清除附件和输入，macOS Option 快捷键保留物理按键。
- macOS 文件监听不再在启动时递归枚举现有文件树，文件变化按受影响子树核对；修复索引连接、租约和退出资源回收。
- 全量索引分批扫描和写入，主动让出 CPU；正文索引需确认资源和隐私提示后开启，关闭后清理残留正文。
- 修复快速搜索时旧结果覆盖新结果的问题，等待和失败状态支持重试当前查询。
- 剪贴板历史可展示原图和 OCR 详情；原生 OCR 在独立进程运行，修复识别结果交付后的退出竞态，复制大图避免主线程重复编码。
- 语音输入使用 Fn/Ctrl 唤起的听写胶囊，提供可选降噪和分级润色；区分认证、超时、上游不可用与模型目录故障。
- Home 统一会话布局，修复恢复历史后的行高测量；模型入口保留本地 CLI 选项，Provider Registry 与 Scene 统一配置和路由。
- 插件在隔离宿主执行，权限答复按插件身份和权限集合归属；安装、启用和取消失败保留真实状态，不把不完整安装标为可用。
- 登录会话支持短期和长期保持登录并安全续期；账号停用、设备撤销和令牌版本变化继续使会话失效。
- 应用管理迁入设置页的分栏列表与详情，收拢高级配置和重复入口，完善骨架加载、空状态和辅助技术反馈。
- 更新分块下载遵守并发上限，持续收到数据时不因固定总时限中断；确认签名地址返回 HTTP 403 后切换备用地址并保留已完成分块。
- 更新后的启动健康确认使用新安装版本，更新页保留本机安装历史；签名和完整性校验继续执行。
- MCP Host 等待旧监听器关闭后再重绑定，并发启动共用同一个监听器，避免端口竞争误关闭功能开关。
- 开发版使用独立单实例锁和临时文件目录，避免与安装版相互清理资源；TuffEx 更新语音、图表和动效组件及双语使用说明。
- Nexus 修正客户端 IP 信任并减少遥测数据库写入，管理台和文档导航同步整理。

## 破坏性变更

- 语音输入浮球和 CoreBox 顶部本地 CLI 按钮已移除；听写通过 Fn/Ctrl 唤起，本地 Agent 从对应管理与项目入口使用。
- 本地 CLI 不再默认参与 AI 路由，使用前需在渠道页手动启用；本机语音识别路由由应用管理，不再出现在可编辑渠道列表。
- 项目会话与附件保持本地，不再进入云同步快照；供应商原生会话记录仍由供应商保存。

## 已知限制

- MCP Host 是默认关闭的 Beta 能力，仅支持本机回环，不纳入 Stable 核心能力承诺；跨平台外部客户端完整闭环尚未验收。
- 本版未声明自动降级兼容，更新故障恢复仍受发布清单和健康确认约束，不保证降级到旧版本可保留全部新数据。
- 原生 Ghostty 渲染器尚未嵌入；前台应用切换推荐的同等设备场景尚未在 Windows 和 Linux 完整覆盖。
- Nexus 中国大陆访问优化仍在评估，本次未切换 DNS、接入额外代理或迁移生产构建。
