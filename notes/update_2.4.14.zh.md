# Tuff v2.4.14 更新说明

## 摘要

- Home 保留听写结束后的语音草稿，支持回放、重新识别和发送为语音消息。
- 整理首页会话布局、项目操作菜单、输入工具条胶囊和模式选择动效。
- 本地 CLI Provider 保留可用模型选项，项目会话与附件继续保持本地存储。
- TuffEx 新增语音播放、流光和语音波形组件；Nexus 减少遥测写入并修复客户端 IP 信任问题。
- 新增本机回环 MCP Host 作为默认关闭的 Beta 可选能力，并加入监听器重绑定稳定性修复。

## 新增内容

- MCP Host 允许兼容的外部 AI 客户端通过本机回环地址调用 Tuff 工具；每次调用仍需用户确认。

## 变更内容

- 听写结束后保留最近一次录音，即使识别失败也能回放或重新识别；发送和丢弃操作明确显示处理状态。
- 会话消息支持保存语音附件，播放组件提供播放、暂停、进度定位、时长和波形控制。
- 统一 Home 会话输出与面板布局，修复恢复历史会话后行高未及时测量的问题。
- 为 Composer 工具条胶囊和模式选择加入过渡动效，并整理项目操作菜单。
- 保留本地 CLI Provider 的模型选项，避免配置加载后可用的本地模型入口消失。
- 云同步快照跳过项目会话，本地项目会话与附件按项目保存。
- 开发版使用独立的单实例锁和临时文件目录，避免与安装版相互干扰。
- TuffEx 新增 TxVoiceClip、TxFlowLight 和有机语音波形，补齐组件示例与交互说明。
- 同步 TuffEx 0.7.0 的版本、组件生命周期与中英文文档，更新新增组件的体积审计基线。
- Nexus 调整遥测查询与索引，减少普通遥测事件的数据库写入，同时保留汇总和清理语义。
- Nexus 在 Cloudflare 环境优先读取 CF-Connecting-IP，避免伪造 X-Forwarded-For 绕过设备授权限流或污染审计记录。
- MCP Host 在端口切换或关闭重启时等待旧 listener 完成释放，避免新旧监听器并发绑定。
- MCP Host 设置页明确显示 Beta 状态，默认关闭并保留用户确认边界。

## 已知限制

- 项目会话保持本地，不提供跨设备同步。
- Nexus 中国大陆访问优化仍在评估，本次未切换 DNS、接入额外代理或迁移生产构建。
- MCP Host 目前仅支持本机回环监听，属于默认关闭的 Beta 能力，不纳入 Stable 核心能力承诺。
